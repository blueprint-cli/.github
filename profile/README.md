# Blueprint CLI

**Define your schema. Generate your stack.**

Blueprint is an open-source configuration format and CLI for schema-driven development. Developers define their schema in a configuration file, and the CLI uses that definition to generate across the application stack.

## One definition, multiple outputs

- Websites and documentation
- APIs and databases
- Desktop and mobile applications

The goal is to keep the shared structure in one place and use it to build the different parts of a project.

Explore the public repositories in this organization for source code and project documentation.
