# Blueprint CLI organization profile

Public copy: `profile/README.md`. Current artwork in `profile/assets/`:

- `logo-v3.svg` and `logo-v3.png` — transparent master mark.
- `avatar-v3.svg` and `avatar-v3.png` — square organization avatar.
- `banner-v3.svg` and `banner-v3.png` — profile banner.

The mark uses three identical 60/120-degree rhombi, rotated by 120 degrees. Each panel uses the same 150-unit edge length and a 12-unit outward offset, giving equal spacing. The exact same geometry is reused in the avatar and banner. Colors are coral #FF805A, ivory #F4F0E8, and charcoal #191B20.

Earlier versions remain as historical explorations. Upload the current avatar separately in organization settings.
